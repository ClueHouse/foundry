# On the Road — v3

Foundry demonstration site for a fictional 24-hour roadside diner.

## V3 changes
- Rebuilt the hero background as a true 16:9 image to stop over-zooming.
- Removed interface text that had been baked into the source image.
- Brightened the diner interior and reduced the heavy black overlay.
- Redesigned the On the Road name as a distinct roadside badge.
- Preserved the expanded interactive menu, location panel and moving ticker.

Open `index.html` locally, or use Live Server in VS Code.
