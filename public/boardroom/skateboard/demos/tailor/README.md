# Ash & Oak

A five-chapter editorial menswear demonstration site.

## Structure
- `index.html` — the complete five-chapter experience
- `shop/index.html` — display-only collection grid
- `css/main.css` — shared styling
- `js/app.js` — chapter navigation, boutique scrolling, and bag drawer
- `images/` — production image assets

## Chapters
1. Arrival
2. The Atelier
3. The Collection
4. The Details
5. Boutiques
