# Clementines — A collection of distinctive retreats.

Premium editorial Springboard site built with semantic HTML5, modern CSS, vanilla JS. No frameworks.

## Run locally
python -m http.server in root

## Structure
- index.html, retreats.html, discover.html, reviews.html, book.html
- css/style.css
- js/main.js
- assets/images/ (~30 placeholder webp)
- assets/icons/

## Design notes
- Warm white, stone, sand, charcoal, forest, ocean, timber, gold palette
- Cormorant Garamond + Inter
- Generous whitespace, parallax Discover page, sticky sections, image reveals
- Reduced motion support
